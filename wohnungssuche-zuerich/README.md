## Eckdaten (Stand 2026-10-08)

- **Ab:** 15.10.2026 (sehr kurzfristig)
- **Dauer:** 14 Tage – max. 1 Monat
- **Miete:** ≤ CHF 550/Monat warm/all-in (ideal < 500)
- **Lage:** ≤ 60 Min ÖV **oder** ≤ 30 Min Velo ab **Zürich HB**
- **Besonderheit:** erste Mietzahlung gestundet (nach 15 Tagen / 1. Monat)

## Realitäts-Hinweis (wichtig)

Der Marktcheck (`03-...`) zeigt: **≤ CHF 550 warm, möbliert, kurzfristig** gibt es
im Pendelraum Zürich praktisch **nicht**; realistischer Boden ~CHF 900–1'100
(Zimmer) bzw. CHF 1'200–1'600 (1-Monats-möbliert). Vor der 100er-Kampagne müssen
daher **Budget / Format / Radius / Meldeadresse-Pflicht** justiert werden.

## Noch zu klären (steuert die Kampagne)

- Budget-Decke realistisch setzen
- Akzeptierte Formate (WG / Zimmer / Studio / Airbnb / Hostel …)
- Meldeadresse/Anmeldung zwingend?
- Nachweis-Dokumente im Erstkontakt (Empfehlung: minimal)
- Arbeitszeiten (angenommen ca. 09:00–16:30), max. tragbare Kaution
